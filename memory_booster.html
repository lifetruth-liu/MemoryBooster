内存加速工具 · 使用文档

一个 Windows 专用的小工具：手动点一下加速，或设个阈值让它后台自动加速（每 5 分钟最多一次）。原理和微软电脑管家的 Boost / Smart Boost 完全一致——都是套壳 Windows 自带 API。已打包为单文件 MemoryBooster.exe（6.9 MB），界面为纯 tkinter 自绘，零第三方依赖。

⚠ 先说最关键的局限
本工具回收不了「非分页池(Non-Paged Pool)」内核内存泄漏。NPP 是内核态内存，用户态的 EmptyWorkingSet / 清缓存都碰不到它。如果机器上有驱动导致的 NPP 泄漏（比如常见的 ~8.5GB 泄漏），请用 RAMMap / poolmon 定位泄漏驱动，或重启。本工具能释放的是「备用缓存 + 可修剪的用户态工作集」，能缓解感知压力，但治不了 NPP 泄漏。

1. 原理：微软电脑管家到底怎么加速的

微软电脑管家的「加速」不是黑科技，本质是把 Windows 自带的内存管理 API 包了一层 UI。下面这张表把它的真实动作和本工具的实现一一对应：

动作微软电脑管家本工具实现需要权限
修剪进程工作集告诉后台进程释放不用的内存SetProcessWorkingSetSize(pid,-1,-1) 即 EmptyWorkingSet管理员（其他用户/系统进程）
清空备用/缓存内存Trim standby memory（同重启效果）NtSetSystemInformation(0x50, MemoryPurgeStandbyList)SeProfileSingleProcessPrivilege
清理临时文件清除 Windows 临时文件夹删 %TEMP% 下超过 7 天且未锁定的文件当前用户
智能加速Smart Boost：超阈值自动跑后台轮询 + 阈值判断 + 最小间隔节流同上
结论
它不改内核调度、不修驱动，释放出来的内存很快会被系统和应用重新占满，效果是短暂回血。所谓「加速」= 一次快速的重启级清理动作。

2. 界面：三个标签，400×496

窗口默认出现在屏幕右下角（按工作区计算、避开任务栏，距边 14px），固定尺寸 400×496，不可拉伸，支持深/浅色两套配色。顶部是三段标签，切换即时生效、无需确认。

标签内容用在哪
加速圆环仪表 + 一键加速 + 上次结果三格（释放 / 修剪进程 / 临时文件）日常手动清一下
自动自动加速开关、阈值模式与滑块、最小加速间隔设一次阈值，之后不管
设置开机自启、关闭窗口行为、清临时文件、检测间隔、深浅色、退出装完先配一遍

加速页

  • 圆环按占用率变色：<70% 蓝、70~85% 橙、≥85% 红，中间直接显示百分比。
  • 加速动效：点下按钮后，圆环与中间数字在约 0.6 秒内平滑涨到 100%（并轻微「呼吸」表示还在干活）；加速完成时圆环再平滑回落到真实占用，按钮变绿显示「✓ 已释放 X.XX GB」，2.4 秒后自动复位成「一键加速」。整个过程只做增量重绘，界面不会闪。
  • 三格统计：本次释放量、修剪成功的进程数、清理的临时文件数。

清晰度、图标与动效实现

这几处是专门为「看着不糊」下的功夫，也解释了为什么界面小但不糊：

问题原因做法
整块界面发虚只声明 System DPI 感知时，缩放≠100% 的屏幕会被系统把窗口位图拉伸改用 Per-Monitor V2 DPI 感知（SetProcessDpiAwarenessContext(-4)），按真实像素绘制
中文小字糊成一团字号用「点」，换算成 12.7px 这类非整数值，笔画被摊到两个像素上字号改用像素（Tk 的负数写法），且最小 11px；正文统一 12~15px
圆角与边框毛糙1px 的 polygon 描边在斜边上是硬锯齿改成双层填充（外层描边色 + 内层留白），坐标全部 round 到整数像素
满环时 12 点有豁口Tk 画接近 360° 的弧，起终点对不齐≥98% 时改用完整椭圆绘制，无缝

图标是内嵌的：app_icon.py 里存着 zlib+base64 压缩的 ICO（16~256 共九档），运行时解压到临时目录供窗口与托盘使用。所以 exe 拷到任何路径都自带图标，不需要 assets 目录；exe 自身的资源段图标则在打包时写入。

自动页

  • 阈值两种模式，滑块直接拖：按已用内存 GB（2 GB ~ 总内存-1）或按占用率 %（50~95）。
  • 滑块下方实时显示「当前已用 X GB，已超过 / 低于阈值」，方便判断阈值定得合不合适。
  • 最小加速间隔 1~15 分钟：自动触发的节流阀，避免反复清缓存反而拖慢系统。手动点按钮不受此限制。

设置页

  • 开机自启：管理员运行时写计划任务（最高权限、免 UAC）；普通权限自动退回登录项，同样不弹 UAC。
  • 关闭窗口时最小化到托盘：默认开，双击托盘图标恢复，右键退出。
  • 加速时清理临时文件：只删 7 天前的，避免误删正在用的文件。
  • 后台检测间隔：5~120 秒步进，越小越灵敏。
  • 深浅色切换、一键退出。

3. 功能清单

  • 一键加速：修剪工作集 + 清备用列表 + 清临时文件，三步一次做完。
  • 阈值自动加速：按 GB 或按百分比，后台线程轮询。
  • 节流保护：自动加速默认 300 秒内最多一次。
  • 开机自启：优先计划任务（最高权限），不可用时自动降级为 HKCU 登录项，两种都不弹 UAC。
  • 托盘常驻：关闭窗口不退出，托盘双击恢复 / 右键退出。
  • CLI 兜底：没有界面也能 --once / --auto 跑。
  • 高 DPI 适配：按系统 DPI 缩放坐标与线宽，不糊、不裁切。

4. 运行方式

推荐直接用打包好的 dist\MemoryBooster.exe：双击即可，无需 Python。配置文件 memory_booster_config.json 会自动生成在 exe 同目录。

EXE 模式（推荐）

# 双击运行，或命令行启动
dist\MemoryBooster.exe

# 开机自启用的静默模式：直接进托盘
dist\MemoryBooster.exe --tray
首次运行请右键 → 以管理员身份运行
非管理员时：清空备用列表（清缓存）会失败，跨会话的系统进程工作集修剪不了，加速效果会打折。开机自启不受影响——会改用普通权限的登录项。

源码运行

# 只依赖标准库（tkinter 一般随 Python 自带）
py -3.10 memory_booster.py

CLI 模式（无界面 / 计划任务）

# 立即执行一次加速后退出，并打印结果
py -3.10 memory_booster.py --once

# 常驻：按 GB 阈值自动加速，每 20 秒检查、最小间隔 5 分钟
py -3.10 memory_booster.py --auto --threshold-gb 12 --check-interval 20 --min-interval 300

# 按占用率阈值
py -3.10 memory_booster.py --auto --threshold-percent 85

开机自启是怎么做的

自启本身不需要管理员权限，需要管理员的只是「免 UAC 以管理员身份启动」这一种组合。程序按当前权限自动选路：

身份用的方式启动后权限弹 UAC
管理员计划任务 MemoryBooster_Autostart管理员不弹
普通用户HKCU\...\Run 登录项 MemoryBooster普通不弹
 
# 管理员：任务计划程序
schtasks /Create /TN MemoryBooster_Autostart /TR "\"C:\path\MemoryBooster.exe\" --tray" /SC ONLOGON /RL HIGHEST /F

# 普通用户：注册表登录项（等价于写 HKCU 的这一条）
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v MemoryBooster /t REG_SZ ^
  /d "\"C:\path\MemoryBooster.exe\" --tray" /f

计划任务创建失败时（组策略禁用任务计划等）也会自动退回登录项，不会直接报错。取消勾选会把两条路都收干净；只有「删除管理员建的计划任务」这一步仍然需要管理员，遇到时会提示提权重启。

两处存的都是绝对路径，把 exe 移动位置后需要重新勾选一次。

界面里的改动会自动写入 memory_booster_config.json（防抖 500ms），也可以直接编辑该文件后重启程序。CLI 的 --threshold-* / --min-interval / --check-interval 只在该次运行生效，不落盘。

threshold_mode阈值类型"gb""gb" 或 "percent"

6. 体积：从 25.8 MB 压到 6.9 MB

v1 用 customtkinter 做界面，单文件 exe 有 25.8 MB。v2 改成纯 tkinter 自绘（所有卡片、圆环、开关、滑块都是 Canvas 画的），并裁掉 Tcl/Tk 里用不到的运行时数据：

版本界面方案体积变化
v1customtkinter 5.225.76 MB—
v2纯 tkinter Canvas 自绘7.39 MB-71.3%
v2.1内嵌图标 + 去掉 tempfile 依赖6.91 MB-73.2%

瘦身来自四件事：① 去掉 customtkinter 及其依赖；② 删除 tcl/tzdata（几百个时区文件）、msgs（本地化消息）、tk/demos、tk/images；③ 排除 numpy / PIL / setuptools / sqlite3 / unittest 等未被引用的模块；④ 图标压成 zlib+base64 直接放进 app_icon.py，不再携带独立资源文件；⑤ 去掉 tempfile 依赖（它会顺带拉进 shutil / bz2 / lzma 约 1.5 MB）。

# MemoryBooster.spec 关键片段
DROP = ("_tcl_data\\tzdata", "_tcl_data\\msgs",
        "_tk_data\\msgs", "_tk_data\\demos", "_tk_data\\images")

a = Analysis(["memory_booster.py"],
             datas=[("assets/icon.ico", ".")],
             excludes=["numpy", "PIL", "setuptools", "sqlite3", "unittest",
                       "customtkinter", "email", "http", "multiprocessing"],
             noarchive=False)
a.datas = [d for d in a.datas
           if not any(d[0].lower().startswith(p) for p in DROP)]

exe = EXE(PYZ(a.pure), a.scripts, a.binaries, a.datas, [],
          name="MemoryBooster", console=False, icon="assets/icon.ico")
# 重新打包
py -3.10 -m PyInstaller --noconfirm --clean MemoryBooster.spec
首次启动会慢 1~2 秒
onefile 需要把内容解压到临时目录；之后系统有缓存就快了。想要秒开可以改成 --onedir，代价是一个文件夹而不是单文件。

7. 局限与 NPP 泄漏排查

本工具能动的只有两块内存：备用/缓存列表（Standby List）和用户态进程的工作集。下面这些它一概动不了：

  • 非分页池（Non-Paged Pool）：内核态内存，用户态 API 碰不到。
  • 分页池 / 驱动占用的内存：同上。
  • 正在活跃使用的内存：修剪只是把「暂时不用」的部分换出，活跃页不会动。

如果任务管理器里「已用内存」远大于所有进程之和，或 RAMMap 显示 Nonpaged Pool 异常大（如几个 GB），按下面顺序查：

# 1) 看谁在占：RAMMap 打开后用 "Use Counts" / "Physical Pages" 排序
# 2) 定位驱动：poolmon 按 tag 排序，找只增不减的 tag
poolmon -b -n MemoryBooster.log

# 3) 用 tag 反查驱动（需要 WDK 的 pooltag.txt，或用 strings 搜 .sys）
findstr /m /c:"TagName" C:\Windows\System32\drivers\*.sys
别指望"加速"解决 NPP 泄漏
微软电脑管家同样救不了 NPP 泄漏——它用的也是这几个用户态 API。真正的根治办法是找到泄漏的驱动并升级/卸载，或者重启。

8. 常见问题

现象原因 / 处理
点了加速，数字几乎没降内存本来就在活跃使用，没有可修剪的部分。这属正常，不代表工具失效。
「清缓存失败」没用管理员身份运行。右键 exe → 以管理员身份运行。
勾了开机自启但没生效先看程序是否把开关记成了「已开启」（下次启动会自动读回来）。若以普通权限勾选，走的是 HKCU 登录项，登录后以普通权限运行——这是正常的，不是失败。另外 exe 移动位置后要重新勾选一次（存的是绝对路径）。
托盘图标不见了Windows 会把新图标收进「隐藏的图标」里，拖到任务栏常显即可；托盘注册失败时程序会自动改为普通最小化。
窗口跑到屏幕外换过显示器/分辨率后右下角坐标变化，双击托盘图标恢复会自动重新定位。
杀软报毒PyInstaller 打包的无签名 exe 常见误报。可自行用本仓库源码 pyinstaller MemoryBooster.spec 重新打包。

验收清单

  • 以管理员身份运行，界面右上角徽标显示「管理员」
  • 点「一键加速」，圆环有旋转动效，结束后弹出「已释放 X GB」
  • 自动页打开开关、设个较低阈值（如占 60%），等 15~20 秒看是否自动触发
  • 设置页勾「开机自启」，注销后重新登录确认托盘里有图标
  • 关闭窗口 → 进托盘；双击图标恢复，且位置仍在右下角
